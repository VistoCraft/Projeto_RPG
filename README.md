# Projeto_RPG
Uma ficha interativa para mestrar RPG

Feito com [Next.js](https://nextjs.org).

## Como rodar

```bash
yarn install
yarn dev
```

Abra [http://localhost:3000](http://localhost:3000).

Para editar o projeto, veja o [CLAUDE.md](CLAUDE.md). A documentação de arquitetura fica em [`ai/`](ai/01-contexto-do-projeto.md).
